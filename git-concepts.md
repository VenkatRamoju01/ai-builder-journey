
# Git Concepts I Have Learned

## 1. Repository
A repository is a project folder tracked by Git.

## 2. Commit
A commit is a snapshot of changes saved in Git history.

## 3. Push
Push uploads my local commits to GitHub.

## 4. Branch
A branch allows me to develop a feature separately without directly changing the main branch.

## 5. Merge
Merge combines changes from one branch into another.
